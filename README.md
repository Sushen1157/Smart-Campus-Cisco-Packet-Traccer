# Smart-Campus-Cisco-Packet-Traccer
Smart Campus Automation Using IoT and Network Configuration
📌 Project Overview
This project presents a Smart Campus Automation System designed and simulated using Cisco Packet Tracer. The project combines IoT (Internet of Things) devices with computer networking concepts to create a connected and automated campus environment.

The system demonstrates how different smart devices and network components can communicate through a structured network to improve campus management, automation, connectivity, and security.
🎯 Objectives
- Design a smart campus network using Cisco Packet Tracer
- Integrate IoT devices with the campus network
- Configure communication between different network devices
- Demonstrate automation of campus facilities
- Apply practical networking and IoT concepts in a simulated environment

📂 Project File

The complete Cisco Packet Tracer simulation is available in this repository:

"Smart Campus Automation Using IOT and Network Configuration.pkt"

To run the project, download the ".pkt" file and open it using Cisco Packet Tracer.

🚀 How to Run
1. Install Cisco Packet Tracer.
2. Download or clone this repository.
3. Open Cisco Packet Tracer.
4. Open the ".pkt" project file.
5. Run the simulation and explore the network topology and IoT configurations.
